# TutorialClass (v1.0)
SCP: Classified Site plugin

Добавляет в игру новый игровой класс - Обучение (как в SCP: SL).

Свойства:
- **Хп:** 100 (но имеет эффект бессмертия);
- **Место спавна:** башня на поверхности;
- **Модель:** перекрашенная в красный цвет моделька охранника.

Чтобы в админ панели была видна иконка класса, поместите в `Plugins/client/[ПЛАТФОРМА]` изображение с названием `tutorial.jpg`.
